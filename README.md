# Anti-Gravity Cargo Network

![Dashboard Preview](https://via.placeholder.com/1200x600.png?text=Dashboard+Preview)

A professional, modern fleet management dashboard built with Vanilla JavaScript, Node.js, and Express. The Anti-Gravity Cargo Network is a full-stack web application designed for next-generation logistical operations.

## Live Preview
🔗 **[View Live on Vercel](https://anti-gravity-cargo-network.vercel.app/)** *(Replace with actual link after deployment)*

## Features
- **Dynamic Dashboard**: Real-time KPI tracking for active jobs, fleet utilization, and on-time rates.
- **REST API Backend**: Node.js and Express backend handling data persistence.
- **Serverless Ready**: Fully configured for Vercel deployment with an in-memory database suitable for serverless scaling.
- **Responsive UI**: A sleek, dark-themed user interface with CSS Grid/Flexbox and glassmorphism elements.

## Tech Stack
- **Frontend**: HTML5, Vanilla CSS, Vanilla JavaScript (ES Modules).
- **Backend**: Node.js, Express, CORS.
- **Deployment**: Vercel.

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Tamanash-009/anti-gravity-cargo-network.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local server:
   ```bash
   npm start
   ```
4. Open your browser and navigate to `http://localhost:3000`.
